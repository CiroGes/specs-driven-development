# SDD Retro

## Inputs
- Completed feature spec and implementation
- Test outcomes and constraints found during delivery

## Expected Output
- Lessons learned note
- Improvements to rules/templates/commands

## Done Criteria
- At least one reusable improvement captured
- Team conventions updated when needed
